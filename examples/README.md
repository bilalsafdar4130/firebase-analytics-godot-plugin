# Examples

Copy-paste starting points. Each one is a whole file that would work in a game.

| | |
|---|---|
| [`analytics.gd`](analytics.gd) | Events, screens, user properties, and a game's own naming scheme. |
| [`ads.gd`](ads.gd) | Banner, interstitial with a cooldown, rewarded with a reward. |
| [`store.gd`](store.gd) | A store screen: prices, buying, entitlements, restore. |
| [`player.gd`](player.gd) | Identity, sign-in, achievements, leaderboards, cloud save. |
| [`privacy_screen.gd`](privacy_screen.gd) | A game's own consent UI, and the delete-my-data button. |
| [`diagnostics.gd`](diagnostics.gd) | A debug screen worth having in every build. |

For the shortest possible version see [`../docs/quick_start.md`](../docs/quick_start.md).
The full demo is [`../demo/scripts/main.gd`](../demo/scripts/main.gd), which runs
from this repository.
